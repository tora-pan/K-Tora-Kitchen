# K-Tora Kitchen

A cozy 3D food-truck management game inspired by Japanese kei trucks and street food culture.

Start with an old, beat-up kei truck and a small roadside spot. Serve customers, improve your recipes, upgrade your truck, and grow your business into a fleet of food trucks across a Japanese-inspired town.

## 🎮 Gameplay

- **Cook & Serve:** Prepare food, fulfill customer orders, and keep customers happy.
- **Upgrade Your Truck:** Improve cooking equipment, storage, appearance, and serving capacity.
- **Grow Your Business:** Earn money, build your reputation, and unlock better locations.
- **Hire Employees:** Automate tasks and manage multiple food trucks.
- **Explore New Locations:** Set up shop at beaches, shopping streets, festivals, and more.

## 🛠️ Tech Stack

- **Game Engine:** Unity
- **Language:** C#
- **3D Modeling:** Blender
- **AI Coding Assistant:** Claude Code
- **Version Control:** Git

## 🚧 Development Status

Early development.

The initial goal is to build a playable prototype featuring:

- One food truck and starting location
- Basic customer AI and queueing
- A simple soba cooking and serving loop
- Customer payments and an in-game economy
- Basic truck and equipment upgrades
- Save and load functionality

## 🚀 Getting Started

1. Install Unity Hub and a compatible Unity Editor version.
2. Clone this repository.
3. Open the project through Unity Hub.
4. Open the main development scene.
5. Press **Play** to test the game.

See `CLAUDE.md` for AI-assisted development guidelines and project conventions.
